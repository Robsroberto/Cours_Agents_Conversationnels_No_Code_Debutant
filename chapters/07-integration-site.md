## Intégrer le chatbot à votre site web ou page Facebook

Ce chapitre couvre les concepts essentiels de intégrer le chatbot à votre site web ou page facebook.

### Introduction

Ce module montre comment publier le widget sur un site WordPress, Shopify ou un site HTML simple, ainsi que l’intégration à Facebook Messenger et WhatsApp Business. Vous verrez les options de personnalisation (couleurs, texte d’accueil) et les réglages de confidentialité conformes aux législations africaines sur les données.
